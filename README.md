# Bank Management System

A comprehensive Python CLI application for managing bank accounts using SQLite database.

## 🚀 Features

- **Account Management**: Add, search, update, and delete customer accounts.
- **Financial Transactions**: Perform deposits, withdrawals, and inter-account fund transfers safely.
- **Data Validation**: Strict input validation using Regular Expressions for phone numbers and email formats.
- **Security**: Protected against SQL Injection vulnerabilities using parameterized queries.
- **Analytics & History**: Track complete transaction history and view real-time bank statistics.

## 🛠️ Tech Stack

- **Language**: Python 3.x
- **Database**: SQLite3

## 💻 How to Run

1. Make sure you have Python installed on your system.
2. Run the main script:

```bash
python bank.py
```
